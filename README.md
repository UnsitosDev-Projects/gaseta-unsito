## Gaceta del Unsito

Este proyecto es la gaceta del Unsito.

## Flujo de trabajo

Se usará Gitflow con las siguientes ramas:

- `dev`: rama de desarrollo. Desde aquí se crearán las ramas `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, entre otras.
- `main`: rama exclusiva para producción y ramas `hotfix`.
